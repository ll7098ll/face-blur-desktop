# 사용자 가이드 (User Guide)

## 1. 프로그램 실행
- **단독 실행 파일**: `얼굴블러.exe`를 더블클릭해 실행합니다.
- **소스 코드 실행**:
  ```powershell
  uv run python -m app.main
  ```

---

## 2. 사진 불러오기 (여러 장 동시 지원)
다음 중 편한 방법으로 사진을 추가할 수 있습니다.
- 창 안으로 **사진 파일 여러 장** 또는 **폴더**를 드래그 앤 드롭
- 상단 **`사진 추가`** 또는 **`폴더 추가`** 버튼 클릭
- 클립보드에 복사한 이미지 붙여넣기 (**`Ctrl+V`**)

불러온 사진들은 왼쪽 **사진 목록**에 등록되며, 백그라운드에서 자동으로 얼굴을 감지합니다.

---

## 3. 얼굴 선택 및 편집
- **특정 얼굴만 블러 해제/다시 켜기**:
  - 사진 위 얼굴 테두리를 직접 클릭하거나, 오른쪽 **감지된 얼굴** 목록에서 해당 번호(`얼굴 #1` 등)를 클릭합니다.
  - 녹색 테두리는 `블러 ON`, 주황색 테두리는 `원본 유지(해제됨)` 상태입니다.
- **미감지 영역 직접 추가**:
  - 오른쪽 **`+ 직접 추가`** 버튼을 누른 뒤 사진 위를 마우스로 드래그하면 수동 블러 영역이 추가됩니다.
  - 수동 영역 오른쪽 위의 `×` 버튼을 누르면 삭제됩니다.
- **원본 비교**:
  - **`꾹 눌러서 원본 비교 (Space)`** 버튼을 누르거나 키보드 **`Space`** 바를 누르고 있으면 블러 전 원본을 즉시 확인할 수 있습니다.

---

## 4. 감지 · 블러 설정
- **부드러운 블러 / 모자이크**: 가우시안 블러와 픽셀 모자이크 중 선택합니다.
- **정밀 감지 모드**: 켜 두면 배경에 작게 찍힌 사람이나 옆모습까지 더 꼼꼼하게 찾습니다.
- **블러 강도 / 범위 여백**: 얼굴 크기와 가리고 싶은 범위에 맞게 조절합니다.
- **감지 민감도**: 값을 낮출수록 더 많은 얼굴 후보를 찾습니다. 조절 후 **`재감지`** 또는 왼쪽 하단 **`전체 재감지`**를 누르면 새 민감도로 다시 분석합니다.

---

## 5. EXIF 없이 안전하게 저장
1. 저장 포맷(`JPEG`, `PNG`, `WebP`)을 선택합니다.
2. **`현재 사진 안전하게 저장`**: 현재 보고 있는 사진 1장을 지정한 위치에 저장합니다.
3. **`전체 N장 폴더에 일괄 저장`**: 대기열의 모든 사진을 선택한 폴더에 `<원본파일명>_blurred.<확장자>` 형태로 한 번에 저장합니다.
4. 저장이 끝나면 EXIF 메타데이터 0건 검증 결과와 저장된 용량이 표시됩니다.
